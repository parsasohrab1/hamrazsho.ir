# هویت بصری «همراز»

**همراز** = کسی که رازت را می‌داند و نگه می‌دارد. دامنه: `hamrazsho.ir` · شناسهٔ بسته: `ir.hamrazsho.app`

## لوگو
دو حلقهٔ هم‌پوشان: حلقهٔ عاجی (شما) و حلقهٔ فیروزه‌ای (همراز). ناحیهٔ مشترک زرین «راز» است. در نوشتهٔ لوگو، نقطهٔ «ز» هم زرین است.

| فایل | کاربرد |
|---|---|
| `hamraz-mark.svg` | فقط نشان (پس‌زمینهٔ شفاف، برای زمینهٔ تیره) |
| `hamraz-icon.svg` | آیکون اپ (کاشی لاجوردی) |
| `hamraz-logo.svg` | لوگوی افقی برای زمینهٔ روشن |
| `hamraz-logo-dark.svg` | لوگوی افقی برای زمینهٔ تیره |
| `exports/` | PNGهای آمادهٔ استور، iOS، اندروید و وب + رنگ‌ها (CSS/JSON/XML/Swift) |

همه با `python build_brand.py` ساخته می‌شوند (و مستقیم در `mental-wellness-assistant/assets` و `public` کپی می‌شوند). اپ از `src/components/BrandMark.tsx` و `Wordmark.tsx` استفاده می‌کند.
