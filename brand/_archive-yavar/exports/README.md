# خروجی‌های آماده برای سایت، اندروید و اپل

این پوشه نسخه‌های آماده‌مصرفِ لوگو و رنگ سازمانی «یاور» است — برای هر دو کانسپت لوگو (`v1` = دایره‌های هم‌پوشان، همان لوگوی اصلیِ فعلاً استفاده‌شده در اپ؛ `v2` = حلقهٔ باز، کانسپت جایگزین). اگر تصمیم گرفتید کانسپت دیگری را نهایی کنید، کافی است اسم پوشه را عوض کنید — ساختار هر دو یکسان است.

## رنگ‌ها
- `colors.css` — متغیرهای CSS برای وب
- `colors.json` — توکن‌های خام (برای هر ابزار دیگری که JSON می‌خواند)
- `android/colors.xml` — برای `res/values/colors.xml` اندروید
- `ios/YavarColors.swift` — برای پروژهٔ Swift/SwiftUI

## لوگو — هر کانسپت (`v1/` یا `v2/`)
| فایل | کاربرد |
|---|---|
| `icon-1024-flat.png` | آیکون کامل، بدون شفافیت، بدون گوشهٔ گردشده از قبل — دقیقاً همان چیزی که App Store Connect و Google Play Console برای آیکون با‌کیفیت‌بالا می‌خواهند (خودشان گوشه‌ها را گرد می‌کنند) |
| `adaptive-icon-foreground-1024.png` | فقط خودِ مارک، پس‌زمینهٔ شفاف، داخل «منطقهٔ امن» آیکون تطبیقی اندروید — برای `android.adaptiveIcon.foregroundImage` |
| `web-icon-{16,32,48,180,192,512}.png` | سایزهای رایج فاویکون/PWA |
| `favicon.ico` | فاویکون چندسایزی کلاسیک برای `<link rel="icon">` |
| `ios/AppIcon-*.png` | سایزهای سنتی iOS (برای پروژه‌ای که مستقیم از Xcode/Asset Catalog استفاده می‌کند، نه اکسپو) |
| `android/ic_launcher-*-*.png` | آیکون‌های mipmap اندروید در تراکم‌های مختلف (برای پروژهٔ Android Studio مستقیم) |
| `android/playstore-icon-512.png` | آیکون ۵۱۲×۵۱۲ برای Google Play Console |
| `android/adaptive-foreground-432.png` | همان foreground، سایز ۴۳۲ (سایز مرجع رسمی گوگل) |

## نکتهٔ فنی: چون این پروژه Expo است
اپ «یاور» با Expo ساخته شده، پس نیازی به Asset Catalog دستیِ Xcode یا پوشه‌های mipmap دستیِ Android نیست — Expo از **یک فایل مربعی منبع** در `app.json` تمام سایزهای لازم را در زمان build می‌سازد. فایل‌های `ios/` و `android/*-dpi-*` در این پوشه فقط برای حالتی هستند که یک‌ وقت پروژه مستقل از Expo (یا یک سایت/اپ دیگر) ساخته شود. برای خودِ اپ فعلی، `icon-1024-flat.png` و `adaptive-icon-foreground-1024.png` مستقیماً در `mental-wellness-assistant/app.json` وصل شده‌اند (نگاه کنید به `mental-wellness-assistant/assets/`).

⚠️ همچنان قبل از انتشار رسمی (استور، ثبت علامت تجاری)، بازبینی توسط طراح گرافیک حرفه‌ای توصیه می‌شود.
