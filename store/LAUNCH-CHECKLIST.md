# چک‌لیست انتشار «همراز» در فروشگاه‌ها

وضعیت: کد برای انتشار آماده است. موارد زیر کارهایی است که **فقط صاحب محصول** می‌تواند انجام دهد (حساب‌ها، کلیدها، اسناد حقوقی) یا باید روی گوشی واقعی آزموده شود.

## ۱. پیش از هر چیز (مسدودکننده)

- [ ] **نام نهایی و لوگو: «همراز» (دامنه `hamrazsho.ir` ثبت شده).** همهٔ لوگوها و آیکون‌ها با `brand/build_brand.py` ساخته می‌شوند و در `brand/exports/` هستند. ⚠️ نوشتهٔ فارسی لوگو فعلاً از فونت Dubai (مایکروسافت) برون‌خط شده؛ پیش از ثبت علامت، لایسنس را بررسی یا حروف را اختصاصی طراحی کنید. استعلام علامت (طبقه‌های ۹، ۳۵، ۴۲) هم باقی است.
- [ ] **شناسهٔ بسته (package id):** `ir.hamrazsho.app` — پس از اولین انتشار **هرگز قابل تغییر نیست**. اگر نمی‌خواهید شناسه «hamrazsho» داشته باشد، همین حالا در `app.config.ts` (`ANDROID_PACKAGE`) و `backend/.env` (`APP_PACKAGE_NAME`) عوضش کنید.
- [ ] **نام حقوقی ناشر** را در `brandConfig.json` → `legalEntityName` بنویسید (در سیاست حریم خصوصی و شرایط استفاده نمایش داده می‌شود).
- [ ] **بازبینی حقوقی** سیاست حریم خصوصی و شرایط استفاده (`src/data/legalDocs.ts`) توسط وکیل.
- [ ] **بازبینی بالینی** بانک سؤال خودارزیابی و مسیر بحران توسط روان‌پزشک/روان‌شناس بالینی (SRS §۸-۱). این کار پیش از انتشار عمومی ضروری است.
- [ ] تأیید شماره‌های اورژانس (`src/data/crisisResources.ts`، `emergencyContacts.ts`): ۱۱۵، ۱۱۰، ۱۲۵، ۱۲۳، ۱۴۸۰.

## ۲. سرور (بک‌اند)

- [ ] سرور ابری داخلی (مثلاً آروان/لیارا/پارس‌پک) + دامنهٔ `api.hamrazsho.ir` → راهنما: `store/DEPLOYMENT.md`
- [ ] `JWT_ACCESS_SECRET` و `JWT_REFRESH_SECRET` واقعی (`openssl rand -hex 32`)
- [ ] پنل کاوه‌نگار + خط اختصاصی → `SMS_PROVIDER=kavenegar`, `KAVENEGAR_API_KEY`, `KAVENEGAR_SENDER_LINE`
- [ ] `CORS_ORIGINS=https://hamrazsho.ir`
- [ ] پشتیبان‌گیری روزانه از پایگاه‌داده

## ۳. کافه‌بازار (کانال اصلی فروش)

- [ ] حساب توسعه‌دهنده (با کد ملی/حقوقی)
- [ ] تعریف دو **اشتراک** در پیشخوان: `hamraz_premium_monthly` و `hamraz_premium_yearly` (قیمت پیشنهادی ۱۴۹٬۰۰۰ و ۱٬۱۹۰٬۰۰۰ تومان)
- [ ] کلید RSA پرداخت درون‌برنامه‌ای → `EXPO_PUBLIC_BAZAAR_RSA_KEY` در `eas.json` (پروفایل bazaar)
- [ ] توکن API پیشخوان → `BAZAAR_API_SECRET` در `.env` سرور (هرگز داخل اپ نه)
- [ ] ساخت: `eas build -p android --profile bazaar` → آپلود APK
- [ ] **آزمون خرید واقعی روی گوشی** با حساب تست بازار: خرید، بازیابی، تمدید، لغو. (کد تأیید سمت سرور با تست خودکار پوشش داده شده، اما SDK پولکی فقط روی دستگاه واقعی قابل آزمون است.)
- [ ] متن و تصاویر فروشگاه: `store/listing-fa.md`

## ۴. مایکت

- [ ] حساب توسعه‌دهنده + ساخت: `eas build -p android --profile myket`
- در این نسخه، خرید درون‌برنامه‌ای مایکت هنوز فعال نیست: بخش‌های «آزمایشی» (ماهی ۱۰ بار رایگان) در مایکت **بدون محدودیت رایگان** هستند. تأیید خرید سمت سرور مایکت آماده است (`backend/src/billing/storeVerifiers.ts`)؛ فقط ماژول بومی SDK مایکت باید اضافه شود (کتابخانهٔ React Native رسمی و به‌روزی برایش نیست).

## ۵. گوگل‌پلی

- [ ] حساب Google Play Console (نیازمند هویت/پرداخت خارج از ایران)
- [ ] ساخت: `eas build -p android --profile play` (فایل AAB)
- [ ] فرم Data safety → `store/data-safety.md`
- [ ] فرم Health apps declaration: «اپ سلامت عمومی/سبک زندگی، بدون ادعای تشخیص پزشکی»
- [ ] در این نسخه پرداخت در گوگل‌پلی فعال نیست (دریافت درآمد Play Billing برای ناشر ایرانی ممکن نیست)؛ بخش‌های آزمایشی بدون محدودیت رایگان‌اند.

## ۶. وب‌سایت (فقط ویترین و مطالعه)

- [ ] `npm run build:web` در `mental-wellness-assistant` → آپلود پوشهٔ `dist/` روی هاست `hamrazsho.ir`
- [ ] آپلود `store/legal/privacy.html` در `/privacy` و `terms.html` در `/terms` (با `npm run export:legal` بازتولید می‌شوند)
- [ ] قرار دادن APK مستقیم در `/download/hamraz.apk`
- [ ] لینک‌های دانلود در `brandConfig.json` → `downloads` پس از انتشار در هر فروشگاه تأیید شود

## ۷. آزمون دستی پیش از انتشار (روی گوشی اندروید واقعی)

- [ ] اولین اجرا: خوش‌آمدگویی، نام، جنسیت، انتخاب صدا، پذیرش شرایط
- [ ] پخش خوش‌آمدگویی صوتی خودمانی با صدای درست (زن برای آقایان / مرد برای خانم‌ها / انتخاب کاربر)
  - ⚠️ بسیاری از گوشی‌ها فقط **یک** صدای فارسی دارند؛ در این حالت صدای جنس مخالف با تغییر زیر و بمی تقریب زده می‌شود. برای صدای واقعی مرد و زن، نصب موتور TTS با صدای فارسی دوم یا سرویس TTS ابری لازم است.
- [ ] تشخیص گفتار فارسی (نیازمند سرویس گفتار گوگل روی گوشی)
- [ ] «کمک فوری» و تماس با ۱۱۵/۱۴۸۰
- [ ] شمارندهٔ ۱۰ بار رایگان در ماه و رسیدن به صفحهٔ اشتراک
- [ ] حذف حساب کاربری و دریافت نسخه‌ای از اطلاعات

## آنچه در این مرحله انجام شد

- ورود با موبایل، همگام‌سازی، **حذف حساب و دریافت داده‌ها** (الزام گوگل‌پلی)
- اشتراک با **تأیید سمت سرور** کافه‌بازار (و آمادهٔ مایکت/زرین‌پال) + جلوگیری از استفادهٔ دوبارهٔ رسید
- مدل درآمد: بخش‌های سلامت روان/بحران/ایمنی **همیشه رایگان**؛ ۸ بخش دیگر **ماهی ۱۰ بار رایگان** (ماه شمسی)، بعد اشتراک
- صفحهٔ شروع با رضایت‌نامه و تأیید ۱۸+، سیاست حریم خصوصی و شرایط استفاده (داخل اپ و وب)
- صفحهٔ اصلی جدید، خوش‌آمدگویی صوتی خودمانی و مسیریابی با گفتار («می‌خوام آشپزی کنم»)، جملهٔ خودمانی در ورود به هر بخش
- انتخاب صدای دستیار (پیش‌فرض: جنس مخالف کاربر؛ یا انتخاب خود کاربر)
- تشخیص گفتار روی اندروید/iOS (قبلاً فقط در مرورگر کار می‌کرد)
- لوگوی دو حلقهٔ هم‌پوشان (حلقهٔ راست در هر بخش به رنگ همان دسته درمی‌آید) + نوشتهٔ لوگو در صفحهٔ خانه و وب
- اپ کاملاً فارسی (گزینهٔ انگلیسی حذف شد)
- وب‌سایت فقط‌خواندنی با لینک دانلود و کتابخانهٔ محتوا
- سخت‌سازی امنیتی سرور، رفع باگ اجرای نسخهٔ تولید در Docker، استقرار با HTTPS خودکار
- حذف بخش‌های نمایشی با داده‌های ساختگی (موسیقی، پیدا کردن آهنگ) از نسخه‌های فروشگاهی
