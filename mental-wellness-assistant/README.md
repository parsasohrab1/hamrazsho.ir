# همراز — اپ موبایل و وب‌سایت

همراه صوتی فارسی برای حال خوب، خانواده، کار و کارهای روزمره. یک کدبیس Expo (React Native +
`react-native-web`) برای **اندروید، iOS و وب**. شناسهٔ بسته: `ir.hamrazsho.app` (پس از اولین انتشار
قابل تغییر نیست).

- بک‌اند (ورود با موبایل، همگام‌سازی، اشتراک): [`../backend`](../backend/README.md)
- انتشار در فروشگاه‌ها و استقرار: [`../store`](../store/LAUNCH-CHECKLIST.md)
- نیازمندی‌های محصول: [`../SRS.md`](../SRS.md)

## اصول (پیش از هر تغییر بخوانید)

- **صداقت:** اپ به هیچ مدل زبانی یا هوش مصنوعی زنده‌ای وصل نیست. پاسخ‌ها از محتوای ازپیش‌نوشته و
  قواعد ساده روی خود گوشی ساخته می‌شوند. هیچ قابلیتی نباید وانمود کند کاری را انجام می‌دهد که نمی‌کند.
- **ابزار آموزشی، نه تشخیص:** خودارزیابی سلامت روان تشخیص پزشکی نیست؛ پرسش‌ها از ساختار مقیاس‌های
  عمومی (PHQ-9، GAD-7 و …) الهام گرفته‌اند ولی نسخهٔ رسمی آن‌ها نیستند. متن همهٔ سلب مسئولیت‌ها یک‌جا در
  `src/data/disclaimers.ts` است.
- **ایمنی اول:** مسیر بحران همیشه اول شماره‌های اورژانس (۱۱۵، ۱۴۸۰، ۱۲۳) را نشان می‌دهد. بخش‌های
  سلامت روان، بحران و ایمنی **هیچ‌وقت** پشت پرداخت نمی‌روند.
- **کاربر تصمیم می‌گیرد:** اپ هرگز خودش پیامک نمی‌فرستد، تماس نمی‌گیرد یا ایمیل نمی‌زند؛ فقط برنامهٔ
  گوشی را با متن آماده باز می‌کند.
- **حریم خصوصی:** بدون حساب هم کامل کار می‌کند و داده فقط روی گوشی می‌ماند. هر تغییری در دادهٔ
  جمع‌آوری‌شده باید هم‌زمان در `src/data/legalDocs.ts` (سیاست حریم خصوصی) ثبت شود و `LEGAL_VERSION`
  بالا برود تا کاربران دوباره تأیید کنند.
- **فقط فارسی:** رابط کاربری کاملاً فارسی است.

## بخش‌ها و مدل درآمد

| وضعیت | بخش‌ها |
|---|---|
| **همیشه رایگان** | خودارزیابی حال روان، رفیق همراه، آگاهی از سلامت روان، گوش فعال، ترک عادت، روابط و زناشویی، قصه برای کودکان، تغذیه و تناسب اندام، کمک فوری |
| **ماهی ۱۰ بار رایگان، بعد اشتراک** | خانواده و اطرافیان، موقعیت‌های اجتماعی، پیشنهاد هدیه، مشاور شغلی، آگاهی حقوقی، کارهای شخصی، آشپزی گام‌به‌گام، مشاور استایل |
| **فقط نسخهٔ توسعه** | موسیقی آرام‌بخش، موسیقی مورد علاقه، پیدا کردن آهنگ (کاتالوگ ساختگی؛ در نسخه‌های فروشگاهی نمایش داده نمی‌شوند) |

- فهرست بخش‌ها، رده‌بندی و قوانین دسترسی: `src/config/features.ts` (`FREE_TRIAL_USES = 10`).
- شمارش استفاده روی گوشی انجام می‌شود و اول هر **ماه شمسی** صفر می‌شود (`src/state/useFeatureUsage.ts`،
  `src/utils/jalali.ts`).
- هر بخش به یکی از شش محور برند (روح و روان، خانواده، حقوقی، کسب‌وکار، تحصیلی، ورزشی) تعلق دارد که
  رنگ لوگو در سربرگ را تعیین می‌کند: `src/config/segments.ts`.

## نسخه‌های ساخت (store flavor)

مقدار `EXPO_PUBLIC_STORE` در هر پروفایل `eas.json` تعیین می‌کند کدام SDK پرداخت لینک شود و پرداخت
چطور رفتار کند (`src/config/release.ts`):

| نسخه | پرداخت | توضیح |
|---|---|---|
| `bazaar` | فعال (Poolakey) | تنها نسخه‌ای که اشتراک می‌فروشد؛ رسید در سرور با API کافه‌بازار تأیید می‌شود |
| `myket` | غیرفعال | بخش‌های ماهانه‌رایگان، بدون محدودیت رایگان‌اند (ماژول بومی پرداخت مایکت هنوز اضافه نشده؛ تأیید سمت سرور آماده است) |
| `play` | غیرفعال | دریافت درآمد Play Billing برای ناشر ایرانی ممکن نیست |
| `web` | — | وب‌سایت فقط‌خواندنی (پایین) |
| `dev` | همه باز | بخش‌های نمایشی هم دیده می‌شوند |

- کتابخانهٔ پرداخت بازار فقط در نسخهٔ `bazaar` لینک می‌شود (`react-native.config.js`) و مجوز بازار از
  بقیهٔ نسخه‌ها حذف می‌شود (`plugins/withStoreFlavor.js`).
- اپ هرگز خودش اشتراک را فعال نمی‌کند: رسید به `POST /billing/verify` بک‌اند می‌رود و فقط پاسخ سرور
  معتبر است (`src/billing/storeBilling.ts`، `src/state/PremiumContext.tsx`).

## صدا

- **گفتار به متن:** روی اندروید/iOS با `expo-speech-recognition` و در وب با Web Speech API. ماژول بومی
  فقط در نسخهٔ ساخته‌شده (EAS یا dev client) وجود دارد، نه در Expo Go؛ اگر سرویس تشخیص گفتار روی گوشی
  نباشد، اپ خودکار به تایپ برمی‌گردد. صدا هیچ‌جا اجباری نیست.
- **متن به گفتار:** `expo-speech`. صدای دستیار به انتخاب کاربر است؛ پیش‌فرض صدای زن برای آقایان و صدای
  مرد برای خانم‌ها (`src/state/useVoiceProfile.ts`). اپ دربارهٔ گرایش کاربر هیچ حدسی نمی‌زند و هیچ دادهٔ
  حساسی ذخیره نمی‌کند؛ کاربر خودش صدا را انتخاب می‌کند. بسیاری از گوشی‌ها فقط یک صدای فارسی دارند و در
  آن حالت صدای جنس دیگر با تغییر زیر و بمی تقریب زده می‌شود.
- **خوش‌آمدگویی و جملهٔ ورود به هر بخش:** متن‌های خودمانی و مسیریابی با گفتار («می‌خوام آشپزی کنم»)
  در `src/engine/greetingEngine.ts`.

## وب‌سایت

نسخهٔ وب یک ویترین فقط‌خواندنی است (`src/web/WebSite.tsx`): لینک دانلود اپ، کتابخانهٔ مطالعهٔ سلامت
روان و حقوقی، شماره‌های اورژانس و قوانین. دستیار صوتی و بخش‌های تعاملی فقط در اپ موبایل‌اند. برای اجرای
کامل اپ در مرورگر هنگام توسعه: `EXPO_PUBLIC_WEB_FULL_APP=true`.

## ساختار کد

```
App.tsx              رضایت‌نامهٔ اولین اجرا، Providerها، وب‌سایت یا اپ
src/
  config/            برند (brandConfig.json)، بخش‌ها و دسترسی، نسخهٔ ساخت، محورهای لوگو
  screens/           صفحه‌ها (Home، Onboarding، Paywall، Settings و صفحهٔ هر بخش)
  engine/            منطق خالص و تست‌پذیر هر بخش (غربالگری، تشخیص بحران، مسیریابی گفتار، …)
  data/              محتوای ازپیش‌نوشته، شماره‌های اورژانس، سلب مسئولیت‌ها، متن قوانین
  state/             Contextها و هوک‌ها (ورود، اشتراک، رضایت، پروفایل صدا، شمارش استفاده، …)
  services/          ارتباط با بک‌اند، ذخیره و همگام‌سازی، موقعیت مکانی
  billing/           طرح‌های اشتراک و اتصال به فروشگاه
  voice/             لایهٔ صدا (TTS/STT)
  components/        اجزای مشترک (لوگو، دروازهٔ دسترسی، صفحهٔ خطا، …)
  web/               وب‌سایت فقط‌خواندنی
plugins/             پلاگین Expo برای تفکیک نسخه‌های فروشگاه
scripts/             خروجی HTML قوانین، تولید دادهٔ ساختگی برای تست
__tests__/           تست‌های Jest
```

**تغییر نام یا لوگو:** فقط `src/config/brandConfig.json` و فایل‌های `assets/` را عوض کنید؛ هیچ صفحه‌ای
نام برند را مستقیم ننوشته است.

## حساب کاربری و همگام‌سازی (اختیاری)

ورود با شمارهٔ موبایل و کد یک‌بارمصرف. بعد از ورود، فقط کلیدهای فهرست‌شده در `SYNCED_KEYS`
(`src/services/syncStorage.ts`) با سرور همگام می‌شوند؛ پاسخ‌های خودارزیابی و عکس‌های مشاور استایل هرگز
فرستاده نمی‌شوند. از «تنظیمات» می‌توان یک نسخه از داده‌ها گرفت یا حساب را برای همیشه حذف کرد (الزام
گوگل‌پلی).

## اجرا و ساخت

```bash
npm install
npm run web                 # وب‌سایت (برای کل اپ: EXPO_PUBLIC_WEB_FULL_APP=true)
npm run start               # Expo Dev Tools
npm run android             # ساخت و اجرای بومی (نیازمند Android Studio)
npm test                    # تست‌ها
npm run typecheck           # بررسی نوع TypeScript
npm run build:web           # خروجی وب در dist/
npm run export:legal        # خروجی HTML سیاست حریم خصوصی و شرایط در ../store/legal/
```

ساخت نسخهٔ فروشگاهی با EAS:

```bash
eas build -p android --profile bazaar    # APK کافه‌بازار
eas build -p android --profile myket     # APK مایکت
eas build -p android --profile play      # AAB گوگل‌پلی
```

آدرس بک‌اند از `EXPO_PUBLIC_API_BASE_URL` خوانده می‌شود (در `eas.json` یا فایل `.env`). روی گوشی واقعی
به‌جای `localhost` از IP شبکهٔ محلی یا آدرس سرور استفاده کنید.
